annoterm

Read it. Mark it. Send it back.

Review Markdown in the terminal. Your comments become precise feedback for Codex, Claude Code, or another coding agent.

$ brew install filipgutica/tap/annoterm

Homebrew builds annoterm from source and installs Rust to do it. New to Homebrew? Install it first.

Commands

annoterm copies feedback after each comment change, and again when you quit with open comments.

  • annoterm README.md

    Open a Markdown file in rendered mode.

  • annoterm copy-feedback README.md

    Copy the feedback again if another app replaced your clipboard.

  • annoterm export README.md --output feedback.md

    Write the feedback to a file. Add --force to replace an existing file.

Keys

Press ? in the app for the full list.

  • a

    Comment on the selected block.

  • Ctrl+R

    Switch between rendered Markdown and raw source.

  • Ctrl+K

    Comment on a raw selection or a rendered block.

  • Ctrl+S

    Save changes in raw mode.

  • q

    Quit from rendered mode and copy open comments.

Good to know

Comments stay outside your document. annoterm stores them in a JSON sidecar under ~/.annoterm and re-anchors them when the source moves.

Saves stop if another process changed the file. There is no merge view.

On Linux, copying can need a helper. Install wl-copy for Wayland or xclip for X11. annoterm falls back to OSC 52.
